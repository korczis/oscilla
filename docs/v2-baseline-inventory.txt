OSCILLA V1 -> V2 BASELINE INVENTORY
===================================
Baseline: commit 95dfa81, index.html (5078 lines, 274,746 bytes); `git show 95dfa81:index.html`.
Specs: the V2 mission specification (architecture/build and visual/functional, reference image
tests/visual/reference.png). Historical record of the V2 extraction (issue V202).
Line numbers are a DRAFT against 95dfa81. index.html moves when oscilla-d3 pushes round 2. Re-map
by NAME; `node freeze/extract.cjs` prints the current section line ranges of any index.html.

Classification legend
  PRESERVE  move as-is (byte-equivalent logic) into the target module; golden vectors must pass
  REFACTOR  same behaviour, new shape (split, inject dependencies, de-globalise); golden must pass
  EXTEND    preserved core plus V2 features layered on top (V1 vectors stay green)
  REPLACE   superseded by a new V2 implementation (V1 kept only as a behavioural reference)
  REMOVE    no V2 counterpart

Ownership (CONVENTIONS.md):
  [X] = V1 extraction (this track): src/js/core/**, src/js/audio/{audio-engine,voice,patterns,
        scheduler,modulation,microphone}.js, src/js/data/{presets,learn}.js,
        src/js/visualization/**
  [S] = visual shell agent: src/index.html, src/styles/**, src/js/ui/**
  [D] = dsp/analysis agent: src/js/analysis/**, src/js/audio/{envelope,additive,filters,stereo,
        offline-renderer,wav,noise}.js
  [Q] = sequencer agent: src/js/sequencer/**
  [B] = bioacoustics data: src/js/data/bioacoustics.js

Proposed deviations from spec §9 (cohesion; no tiny modules):
  - src/js/core/config.js: defaultInstrumentState + coerceLike + paramDescriptor + a pure
    applyConfig/validateConfig + serializeConfig. Today these are spread over the constants, the
    component and the URL code. url-state.js keeps only the hash <-> config codec.
  - src/js/visualization/p5-host.js: the shared p5 lifecycle (density, resize, visibility,
    reduced motion, palette cache, label/axis helpers). V2 runs several p5 views, and duplicating
    this scaffolding into each one is the alternative.
  - src/js/core/platform.js: browserName/platformName (Device & Limits). navigator is injected.
  - No src/js/core/namespace.js or events.js. V1 has no event bus: AudioEngine.on/_emit stays in
    audio-engine.js. Add a bus only if a second publisher appears.

F. HIDDEN COUPLING REGISTER (extraction hazards, ordered by severity)
------------------------------------------------------------------------------------------------
K1  Templates call script-global helpers directly: formatFrequency (L261, 266, 297, 341, 343,
    398, 402, 592, 626, 829, 846, 847), formatPeriod/formatWavelength (L282), formatCents (L626),
    sig (L635, 637, 679). In V1 these are top-level bindings of a classic script.
    Inside an ES-module bundle they are out of Alpine's expression scope, which gives empty text
    and ReferenceErrors at runtime that no unit test sees. Fix: expose them on the component
    (e.g. a `fmt` object) or as Alpine magics. Then check every template expression in the
    V2 markup.
K2  syncViz (D47) carries live audio updates (engine.updateLive) and sets planFreqs/planError/
    planWarnings, so readouts, warnings, transport text and live control depend on the
    visualization effect running.
K3  viz.pull (D28) reads engine private structure (ctx, voice.t0, voice.plan, analyser, timeData,
    mic). A voice.js split breaks the p5 views silently.
K4  _holdEnv relies on envLog via _loggedParam (D21). A new ADSR/envelope module must schedule
    through the logged param or provide value-at-time. Otherwise Firefox releases jump (click).
    Chromium never exercises this path; only the mock-engine golden does.
K5  Node accounting (D22): only nodes created through track()/source() are counted and
    disconnected. Filter/additive/stereo builders from [D] must register their nodes, or the
    "zero active nodes after stop" check stops detecting leaks.
K6  applyConfig results depend on this.safeMax (provisional 44.1 kHz before the first gesture vs
    the real rate), and ensureAudio re-applies pendingHashConfig. URL/preset restore order is
    stateful (golden freezes both @null and @48000).
K7  Module singletons shared across sections: engine (component, bridge, error handlers, test
    seam), viz (component, sketch), uiNotify/alertSeq/modalInstances. The UI writes
    engine.lastError (notify, window handlers).
K8  The renderer mutates the bridge: p5 setup assigns viz.resize and viz.p5, and the component
    calls viz.resize on mode change.
K9  CSS-variable contract: readPalette reads --c-bg/surface/line/fg/muted/accent/accent2/warn/
    danger. V2 tokens are --osc-*. On a mismatch, readPalette falls back to hard-coded light
    colours with no error.
K10 DOM contracts used by logic: [data-oscilla-modal][aria-modal="true"] (Space suppression),
    #themeMenu/#themeButton, #preset-tabs, header (trackHeaderHeight -> --header-h),
    x-ref fmap/vizCanvas, document.body x-data (tests), ids 'tab-<mode>' (modeKey focus).
K11 Engine event -> pattern state: onEngine('ended') reseeds pp.random.seed with Math.random
    (preview/playback parity depends on it).
K12 Startup order: CDN defer order (p5, Flowbite, Alpine) + 'alpine:init' + Flowbite auto-init on
    data-attributes vs Alpine x-for-rendered tabs. Bundling changes all three.
K13 Plan labels are UI strings built in DSP planning (D18) and reused by history entries (stored
    in sessionStorage), so changing a label changes stored data.
