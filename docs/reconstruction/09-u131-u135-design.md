# 09. U131 and U135 implementation design: title bar, instrument strip, phone keys

This is the architect's design for the central slice of model E. It was drafted read-only
against `main` at `67ba3253` and against open PRs #647, #654 and #655. The reconstruction
coordinator (oscilla-60) approved it on 2026-11-25; the decisions are recorded in plan issue
Q115. Every pixel figure is an estimate from the CSS: the builder measures each one first and
records before and after in the PR.

## Preconditions

- **Merge order.** #647 (Sonda), #654 (U127, the play table) and #655 (U134, the letter-key
  switch) land first, because all three edit the footer.
- **Size budgets.** These files sit at or near their caps:

  | File | Size | Cap |
  |---|---|---|
  | `src/index.html` | about 322 000 | 322 000 |
  | `ui/workbench.js` | about 39 931 | 40 000 |
  | `main.js` | about 51 410 | 52 000 |

  New code therefore goes into new modules (`ui/strip.js`, `analysis/output-level.js`). Each PR
  deletes, in the same commit, the markup it replaces.

## The merged title bar (PR D)

One `<header role="banner" data-osc="header">`, 56 px tall, built on the Flowbite Pro navbar and
breadcrumb pattern. It replaces both the navbar and the page header.

From left to right it holds:

1. The sidebar or drawer toggle.
2. The brand link, which is also the breadcrumb home.
3. The group crumb, from 1024 px.
4. The one h1. It names the place: `<h1 :id="'osc-title-' + workspace" data-osc="page.title" tabindex="-1">`. The id is bound per place, because `link-integrity` refuses duplicate heading ids (amended by the U132 design, 11, and Q116).
5. The tab crumb, after the h1 and outside it.
6. Search: `w-64` from 1536 px, `w-48` from 1024 px, and an icon below that.
7. **Související**, a menu at every width. The summary is its first line.
8. Theme, help, the overflow menu, and Export.

Related changes:

- `<main :aria-labelledby>` names the same per-place id.
- The Playground's lead sentence becomes `<p data-osc="page.lead">`.
- The duplicate `safety.reopen` button is removed. The overflow menu keeps
  `safety.reopenMenu`.

## The instrument strip (PRs A1, B, C)

The strip replaces the footer. It is the last flex child of the 100dvh column, so it takes its
height from `<main>` and never overlaps it.

- **Landmark.** `<section id="osc-strip" aria-label="Nástroj">` is one region landmark, outside
  `main`. A tiny contentinfo holds the version.
- **Hooks.** The existing ids and data-osc hooks stay, so suites keep their selectors.
- **Legacy styles.** Every `.osc-statusbar` and `.osc-sb-*` class goes, together with its CSS,
  and the Flowbite ratchet falls.
- **Height.** 56 px collapsed. A phone adds `env(safe-area-inset-bottom)`.

The regions, in DOM and Tab order:

1. **Play/Stop** from U127's `PLAY_TARGET`, visible at every width wherever the play table
   does not hide it (Q115 decision 1).
2. **Subject.** `lensSubject(soundingOwner)`, the same source Sonda uses, for example "Zní:
   Synth". Idle shows "Nic nehraje".
3. **Readout.** The existing five fields, with the drop-from-the-end rule.
4. **Observed level.** Peak dBFS read from the existing engine analyser after the ceiling, with
   no new AudioNode, at 10 Hz or less, only while something sounds. It is labelled "relativní
   dBFS, pozorováno". The LED carries `data-led` and `data-source="output.analyser"` and is lit
   at −60 dBFS or above. It replaces the `.osc-status-dot` glow.
5. **Klávesy.** The `keyboard.handle`.
6. **Sonda.** At every width. The navbar button from #647 is removed.
7. **Letter-key switch.** `keyboard.arm`, from U134.
8. **Další.** Uložit preset, Odkaz, Snímek, Exportovat zvuk, Nastavení.

Keys in the strip (PR B):

- `#osc-keyboard` moves into the strip and stays in flow.
- The fixed dock, `<main>`'s compensating margin and the Studio's padding go.
- `--osc-dock-h` keeps its meaning.
- `mountDockYield` mounts its handle into the strip.
- The Playground's keys live in the strip too, folded (Q115 decision 2).

Phone sheet (PR C, which is U135):

- The keys panel itself is drawn as a non-modal bottom sheet, opened from the strip.
- The Synth opens it by default; other places start with it closed.
- At 320 px, `keysOctaves` drops the top C so every white key stays 44 px or wider.
- Black keys stay 24 px or wider (Q115 decision 4).

## State ownership

No new canonical state is introduced.

- **Keys open:** dock-yield's existing user expansion.
- **The level:** a transient observation that is neither stored nor linked.

A census change listed above is expected and is accepted with that reason. Any other change is
a defect.

   desktop.
4. The suites that select the status bar or the keys:
   - `ui-current phone-whole` reads `.osc-statusbar` (change it in A1);
   - `iphone.cjs`;
   - `touch-audio.cjs` (`project.a-phone-sounds`).
5. The size caps, measured before each push.
6. A real iPhone's safe-area inset adds 34 px, which no emulation shows.
